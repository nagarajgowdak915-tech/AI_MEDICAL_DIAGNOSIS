
# Explainable AI for Medical Diagnosis Prediction

## 1. Project Overview
This project uses machine learning to predict the diabetes outcome from health measurements. It also uses Explainable AI (SHAP) to help explain the features that influence model predictions.

This is an educational prototype, not a medical diagnostic tool.

## 2. Objectives
- Build a machine-learning model for diabetes outcome prediction.
- Evaluate the model using test data.
- Explain model predictions using SHAP.
- Provide a simple web interface using Streamlit.

## 3. Technologies Used
- Python
- Pandas
- Scikit-learn
- SHAP
- Matplotlib
- Streamlit
- Visual Studio Code

## 4. Dataset
The project uses a diabetes CSV dataset containing health measurements such as glucose, BMI, age, blood pressure, and an outcome label.

## 5. Model
The model uses Logistic Regression with StandardScaler.
The dataset is split into training and testing sets.

## 6. Explainable AI
SHAP (SHapley Additive exPlanations) is used to estimate how features influence model predictions.

## 7. Current Results
Initial test accuracy: 71.43%.

This result is from an educational experiment and does not establish clinical reliability.

## 8. Project Files
- diabetes_prediction.py: Model training and analysis.
- app.py: Streamlit web application.
- diabetes.csv: Dataset used by the application.
- shap_feature_importance.png: Saved feature-importance chart.
- README.md: Project documentation.

## 9. How to Run
1. Open the project folder in VS Code.
2. Activate the virtual environment if it is not already active.
3. Install the required packages if necessary:
   pip install pandas scikit-learn shap matplotlib streamlit
4. Run the web application:
   python -m streamlit run app.py
5. Open the local address displayed in the terminal, usually http://localhost:8501.
